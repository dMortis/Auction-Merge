# Как добавлять иконки и тени

Сцена: Assets/_Game/Scenes/AuctionMerge_PlayableAd.unity.

## Иконка на доске

1. В Hierarchy откройте Canvas → Background Content → BoardItems.
2. Выберите Cell_01 … Cell_20. Нумерация идёт слева направо, затем сверху вниз.
3. Перетащите Assets/_Game/Prefabs/UI/BoardIcon.prefab в нужную ячейку в Hierarchy.
4. У добавленного BoardIcon в компоненте Image замените Source Image на свой PNG-спрайт.
5. Сохраните сцену. При необходимости измените отступы RectTransform для конкретной иконки.

BoardIcon уже растягивается внутри ячейки с небольшим отступом, сохраняет пропорции изображения и содержит Shadow. Для примера в префабе выбран цилиндр. Можно заменить его любым игровым предметом, замком или ключом. Raycast Target выключен, чтобы изображение не блокировало нажатия на игровые ячейки.

Чтобы создать изображение вручную: выберите ячейку, создайте UI → Image, назначьте Source Image, включите Preserve Aspect и растяните RectTransform по родителю с небольшими отступами.

## Почему перетаскивание PNG в Scene прячет его за фоном

Обычное перетаскивание спрайта в Scene обычно создаёт SpriteRenderer в игровом мире. В этой сцене фон является UI Image в Canvas режима Screen Space Overlay. Интерфейс Canvas рисуется поверх игрового мира. Для элементов доски используйте UI Image внутри Canvas.

Внутри одного Canvas порядок задаёт Hierarchy: более поздние соседние элементы рисуются поверх предыдущих. Background Content стоит первым; его изображение рисуется раньше дочерних BoardItems. Safe Area и Collections расположены поверх фоновой иллюстрации.

## Тени от иконок на доску

Для этой сцены подходит стандартный компонент UnityEngine.UI.Shadow на том же объекте, что и Image. Он создаёт смещённый полупрозрачный силуэт иконки с учётом альфа-канала PNG.

Настройки в BoardIcon:

- Effect Color: тёплый тёмно-коричневый, alpha 0.32.
- Effect Distance: X = 4, Y = -6.
- Use Graphic Alpha: включено.

Смещение вниз и вправо соответствует свету слева сверху в иллюстрации. Для визуального подъёма иконки можно увеличить смещение и немного уменьшить alpha. Стандартный Shadow не размывает силуэт. Для мягкой размытой тени нужен отдельный подготовленный PNG тени или UI-шейдер с размытием.

## Collections

Canvas → Safe Area → Collections содержит три CollectionCard_Background как отдельные UI Image: Collection01, Collection02, Collection03. Добавляйте персонажей, ключи, индикаторы и надписи дочерними элементами соответствующей карточки. Они появятся поверх рамки и пергамента.

ResponsiveBoardBackground размещает ряд под ножками доски, сохраняет пропорции карточек и уменьшает его при нехватке вертикального места. На коротких экранах он также ограничивает высоту доски, оставляя место для ряда. Background Content должен иметь Local Scale = 1: адаптацией размеров занимается компонент.

Меню Auction Merge → Set up board icons and collections повторно настраивает контейнеры и привязки в открытой сцене. Build playable ad scene полностью создаёт сцену заново; для обычного добавления иконок используйте готовую Hierarchy и BoardIcon.prefab.
